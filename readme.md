# SMU IGD ILP - Group 5 - Automating Accounts Payable Data Entry 

## Abstract

Leveraging LLM to automate the data entry process for accounts payable, this project aims to reduce manual effort, minimize errors, and improve efficiency in financial operations. By integrating advanced natural language processing techniques, we can extract relevant information from invoices and other financial documents, streamlining the workflow for businesses.
