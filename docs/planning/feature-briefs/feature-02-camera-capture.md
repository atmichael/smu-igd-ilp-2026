# Camera Document Capture

**Priority:** Must-have

As an accounts-payable user, I want to capture a document with my device camera so that a paper invoice can enter the document-processing workflow without first being scanned separately.

The user can start a capture, preview the image, retake it, or accept it for processing. If camera access is unavailable or denied, the user receives a clear explanation and can leave the workflow without losing existing work. An accepted image remains associated with its source.

Keep this feature to capturing one document at a time. Do not include mailbox collection, OCR behavior, classification, AP matching, or payment approval.
