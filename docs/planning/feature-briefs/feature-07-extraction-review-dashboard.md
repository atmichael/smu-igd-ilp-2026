# Invoice Extraction Review Dashboard

**Priority:** Must-have

As an accounts-payable user, I want to compare a supplier invoice with its extracted fields and line items so that I can correct mistakes before the invoice is used for matching.

Show the source invoice and candidate fields and line items together. Route uncertain, invalid, or failed verification results to a review queue with clear reasons. Let the user correct values, compare them with the source, and confirm or discard the result. Record corrections and distinguish confirmed data from unreviewed extraction.

Clarify which invoice fields are shown and what confirmation does. Keep automatic clean-record completion, mailbox management, extraction internals, procurement-evidence review, matching exceptions, and payment approval out of scope.
